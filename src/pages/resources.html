resources

things worth reading.

security, backend engineering, and a few things that don't fit a category. these are things i actually use, not a link dump.

start here

roadmap.sh when i don't know what to learn next, this usually gets me unstuck. refactoring.guru the one place design patterns finally clicked without making me hate design patterns. Stanford CS106A good lectures. even if you already code, it's worth it for the fundamentals.

security

PortSwigger Web Security Academy solid hands-on labs. OWASP baseline security mindset. not flashy, just necessary. LiveOverflow real-world hacking explained properly, without the fake drama. Project Zero dense writeups from people who actually break things for a living. always worth the time.

low-level / systems

Low Level Learning the thing that got me into low-level stuff without making it feel like homework. Designing Data-Intensive Applications still one of the best systems books. read it slowly and take notes. Effective Go the official Go style guide i still point people to first.

practice / tools

explainshell paste a shell command and it stops looking like wizard text. regex101 the regex tester i actually trust, mostly because it explains itself. Hack The Box good when you want more pressure than a tutorial can fake.
